接入说明

通过统一的音乐接口调用多个 Suno 账号。

你的网关地址

应用请求使用独立 API 密钥。账号由网关按可用状态与权重选择。

开始接入

  1. 在“账号管理”添加账号，检查登录状态和额度。
  2. 在“API 密钥”创建应用密钥，并安全保存。
  3. 在请求中加入 Authorization: Bearer 你的密钥。
